DURGESH — PORTFOLIO

FILES
- index.html: all page content and project links
- style.css: responsive design, colors, animations and layout
- script.js: scroll reveal, portrait interaction and preview fallback
- assets/durgesh-profile.png: portrait image used in the hero

RUN LOCALLY
1. Extract the ZIP file.
2. Open the durgesh-portfolio folder.
3. Double-click index.html, or open the folder in VS Code and use Live Server.

PUBLISH ON GITHUB PAGES
1. Create a repository (or use your portfolio repository).
2. Upload all files and the assets folder, keeping the folder structure unchanged.
3. In repository Settings > Pages, deploy from the main branch and root folder.

PUBLISH ON VERCEL
Import the folder/repository as a static site. No build command is needed; output directory is the project root.
